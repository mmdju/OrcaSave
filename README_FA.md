## درباره پروژه

**اورکا سیو (Orca Save)** ربات تلگرام برای دانلود ویدیو و عکس از شبکه‌های اجتماعی است. کافی‌ه لینک را بفرستی — ربات فایل را می‌گیرد و با کپشنش برمی‌گرداند توی چت.

کل محیط ربات دوزبانه است (فارسی/انگلیسی) — هر وقت خواستی با `/lang` عوضش کن.

---

## پلتفرم‌های پشتیبانی‌شده

* **𝕏 (توییتر / ایکس)** — توییت، ویدیو، عکس
* **اینستاگرام** — پست، ریلز، استوری
* **تیک‌تاک** — ویدیو
* **یوتیوب** — ویدیو، با انتخاب کیفیت (بهترین / 720p / صوتی MP3)
* **فیسبوک** — ویدیو و پست
* **تردز** — پست
* **پینترست** — پین
* **توییچ** — کلیپ

---

## امکانات

* **دانلود با یک لمس:** هر لینک پشتیبانی‌شده را بفرست، فایل را توی چت تحویل بگیر.
* **انتخاب کیفیت:** روی لینک‌های یوتیوب بین بهترین کیفیت، 720p یا صوتی MP3 انتخاب کن.
* **ترجمه کپشن:** پست‌های متنی (توییت، تردز، بیو، کلیپ توییچ) دکمه ترجمه دارند.
* **دو زبان:** سوییچ بین فارسی و انگلیسی با یک لمس (راست‌به‌چپ کامل).
* **راهنما:** آموزش استفاده از ربات با دستور `/help` داخل خود ربات.

---

## دستورات ربات

| دستور | توضیحات |
| :--- | :--- |
| `/start` | شروع ربات |
| `/help` | آموزش استفاده از ربات |
| `/lang` | تغییر زبان (فارسی / انگلیسی) |

برای دانلود هیچ دستوری لازم نیست — فقط لینک ویدیو یا عکس را بفرست.
